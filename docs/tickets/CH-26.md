## Status

in progress (2026-11-23), Milestone C

## Depends on

## Scope

- `.github/workflows/test.yml`: on push and pull request, run the full suite, `py_compile`, and `sh -n`/`dash -n` on the hook template, on `ubuntu-latest` and `macos-latest`, with the oldest and newest supported Python 3 (state the minimum version in the README).
- Git identity and `TMPDIR` set for the real-git tests; no secrets, no network beyond checkout.
- Pinned action versions (full commit SHA) and `permissions: contents: read`.

Note: the workflow only runs once the owner pushes; the first run's result is recorded after that push.

## Done criteria

- The workflow file passes a YAML parse and an actionlint-style read by the reviewer.
- The suite passes locally under the stated minimum Python, if available (or say not possible here).
- After the owner's push: the first run's result is recorded in this ticket (by the coordinator). Review rounds: at most 2.

## Allowed files

`.github/workflows/`, `README.md` (minimum Python, badge), `tests/` (only if a test is not portable to Linux)
