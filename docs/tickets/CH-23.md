# CH-23: Board title from a tracker column with another name

## Status

planned (2026-11-23), Owner request 2026-11-23 (CH-21 follow-up)

## Depends on

none

## Scope

CH-21 found that one private project's tracker names its title column something other than `Title`, so rows without a ticket file show no title. Old tickets stay as they are (owner rule: differences are mapped through settings, never by rewriting tickets).

- New optional setting `tickets.titleColumn` (a header name, matched ignoring case). Default: `Title`, then a short built-in list of common synonyms (`Issue`, `Summary`, `Name`, `Subject`).
- Title shown on a card: the ticket file's `# <ID>: <title>` heading if there is a file, else the title column cell (Markdown links reduced to their text, escaped as all text is).
- The title column is no longer shown again as an extra column.
- `harness_config` validates the new key.

Don't: rewrite any tracker or ticket; change `--check` results.

## Done criteria

- Fixture tests: `Title`, a synonym, `titleColumn` set, a row without a file shows the cell's text, a row with a file prefers the heading, a link in the cell, hostile text escaped.
- This repo: `--check --root .` exit 0.
- Full suite passes. Review rounds: at most 2.
