## Scope

`dev-harness-board` (no flags) writes `tickets.boardPath` as one self-contained HTML file: no network, no external scripts, fonts or images.

- **Columns:** Planned | In progress | In review (In review and Fixing) | Owner check | Blocked (Blocked and Deferred) | Done.
- **Cards** show:
  - kind icon, from `idPrefixes` or a ticket-file label;
  - ID, title, labels;
  - review badge from the Review column: high-risk, standard or self-review;
  - a mismatch badge when `--check` would report this ticket;
  - extra columns from `extraColumns`.
- **Filters and search:**
  - text search over ID and title;
  - filters by kind, platform and review level;
  - a "mismatches only" toggle.
- **Issue view:** clicking a card opens the ticket rendered from its Markdown, with:
  - a details panel (state, review, commit, extras);
  - a twin link;
  - a copy-link button;
  - a `#<ID>` deep link that opens the view when the page loads.
- **Markdown:** a small, safe renderer (headings, lists, code, links, tables, emphasis). All ticket text is escaped first; links only allow `http`, `https`, relative paths and `#`.
- **Look and freshness:**
  - light and dark themes (follows the system, with a toggle);
  - usable at phone width;
  - a "built at <time> from <commit>" line;
  - a stale warning in `--check` when the board file is older than the tracker or any ticket file (the page itself can't read local files, so it only shows its build time).
- **Output:**
  - written atomically (temp file plus rename);
  - the build is deterministic apart from the build-time line, so rebuilds don't churn diffs;
  - `--out <path>` overrides `boardPath`.

Don't: fetch anything at view time; use `innerHTML` with unescaped ticket text.

## Done criteria

- Tests:
  - every column and badge;
  - escaping (`<script>`, `"`, `javascript:` links, HTML in titles and in table cells);
  - deep-link handling, present in the output;
  - deterministic output for the same input;
  - an atomic write (no partial file on error).
- A generated board for a fixture project opens in a browser with no console errors. Screenshot it (light and dark) as evidence in the scratchpad, not committed.
- Full suite and static check pass. Review rounds: at most 2.
