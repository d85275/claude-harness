# CH-05: Warn when a commit adds generated or ignored-looking files

## Status

planned (2026-11-22); catch list and layout updated after CH-08

## Depends on

CH-08 (rules go in `bash_rules.py`); CH-01 (`tickets.boardPath`)

## Scope

On a Bash `git commit`, list the files the commit would add, and ask when any of them looks generated.

### Must catch

Commit forms:
- `git commit`
- `git commit -m "msg"`, `-am "msg"`, `--all`
- `git -C <dir> commit`
- chained after other commands (`make && git commit -m x`)

Files that make it ask, when staged as added:
- anything under `node_modules/`, `build/`, `dist/`, `.gradle/`, `DerivedData/`, `__pycache__/` or `.worktrees/`
- `*.pyc`, `*.class` and `*.o` files
- the configured board output (`tickets.boardPath`)
- a file the repo's `.gitignore` would ignore (`git check-ignore --no-index`), i.e. force-added

The prompt lists up to 10 paths.

### Must pass

- commits that add only ordinary source and docs files
- commits that only modify or delete files
- `git commit --amend --no-edit` with nothing new added

### Known gaps (document in README, do not chase)

- **`git add -A && git commit` in one command:** the hook runs before the add, so it sees only what was staged earlier.
- commits made through aliases, scripts or other tools

### How

- **Where:** detection goes in `bash_rules.py`, reusing `ShellCheck`'s segments and `Budget`.
- **Git calls:** run `git diff --cached --name-only --diff-filter=A` and `git check-ignore --no-index --stdin` only when a commit is detected, with one shared 3 s deadline.
- **Failure:** this is a warning feature, so if git fails, allow the call. Never allow silently, though: add a `systemMessage` saying "could not check staged files: <error>".

## Done criteria

- Tests with a temporary repo for each must-catch and must-pass item, plus a git failure that allows with a warning.
- README hooks table and known gaps updated.
- Full suite passes.
- Review rounds: at most 2. Findings outside the catch list become documented gaps or a follow-up ticket.
