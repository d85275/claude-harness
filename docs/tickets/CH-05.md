# CH-05: Warn when a commit adds generated or ignored-looking files

## Status

planned (2026-11-22)

## Depends on

CH-01 (`tickets.boardPath`)

## Scope

On a Bash `git commit`, list the files the commit would add (`git diff --cached --name-only --diff-filter=A`; with `-a`/`--all`, also tracked modifications do not count as additions). Ask when any added path:

- sits under `node_modules/`, `build/`, `dist/`, `.gradle/`, `DerivedData/`, `__pycache__/`, `.worktrees/`, or is a `*.pyc`/`*.class`/`*.o` file;
- matches the configured board output (`tickets.boardPath`);
- would be ignored by the repo's `.gitignore` (`git check-ignore --no-index`). A force-add got it staged.

The prompt lists up to 10 paths.

Known limit, to document: `git add -A && git commit` in one command is checked before the add runs, so it sees only what was staged earlier. The hook says so instead of pretending to cover it.

Never block on git errors: if any git call fails, allow.

## Done criteria

- Tests with a temporary repo: plain source file passes; `node_modules/x.js` asks; force-added ignored file asks; board path asks; git failure allows.
- README hooks table updated, including the limit.
