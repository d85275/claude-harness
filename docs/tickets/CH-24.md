# CH-24: Sample project and board example

## Status

in progress (2026-11-23), Milestone C

## Depends on

none

## Scope

A made-up sample project that shows the board, for the README and for people to open.

- `examples/sample-project/`: about 15 made-up tickets (a neutral domain, no real names) covering every column, a twin pair, a high-risk ticket, an owner check, a blocked one, an archived one and one deliberate mismatch, with its own `.claude/harness.json`.
- `docs/examples/board.html`: the generated board for it, committed, so people can open a working board (and later via GitHub Pages).
- `docs/images/`: light and dark board screenshots and one issue-view screenshot (PNG, reasonable size), made with headless Chrome.
- `scripts/make-examples.sh` (or a documented command) regenerates the board and screenshots; the board build is deterministic apart from the build line.

Don't: use any ticket text, ID or prefix from a real project.

## Done criteria

- `dev-harness-board --check --root examples/sample-project` reports exactly the one planted mismatch.
- The committed board equals a fresh build apart from the build line (a test).
- Screenshots exist and are viewed by the coordinator.
- Full suite passes. Review rounds: at most 2.
