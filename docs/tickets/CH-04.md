# CH-04: Ask before `git stash` with other worktrees, and before changing `core.hooksPath`

## Status

planned (2026-11-22)

## Depends on

CH-01

## Scope

- **Stash:** the stash is shared by every worktree of a repo, so a stash made by one agent can be popped by another. When `git worktree list --porcelain` shows more than one worktree, ask before `git stash` (bare, `push`, `save`, `pop`, `apply`, `drop`, `clear`). Read-only forms (`list`, `show`) pass. With a single worktree, nothing changes.
- **Hooks path:** `core.hooksPath` replaces `.git/hooks`, which silently disables hooks such as Git LFS's pre-push. Ask before setting or unsetting it (`git config [--local|--global] core.hooksPath …`, `--unset`). Also ask for per-command `git -c core.hooksPath=…`. Reading it (`--get`, plain `git config core.hooksPath`) passes.
- If `git worktree list` itself fails, do not ask and do not block. Note this in a comment.

Don't: guard other `git config` keys.

## Done criteria

- Tests: stash variants with one and with two worktrees (temporary repo built in the test), read-only stash forms, `core.hooksPath` set/unset/get/`-c`, and a failing `git worktree list`.
- README hooks table updated.
