# CH-22: Guard asks before installing or removing the board's git hooks

## Status

in progress (2026-11-23), owner request after the CH-17 review

## Depends on

CH-17

## Scope

`dev-harness-board install-hooks` and `uninstall-hooks` change `core.hooksPath` through their own `git config` call. So the guard's CH-04 rule, which asks before shell commands that change `core.hooksPath`, doesn't see them.

- **Bash rule:** ask before `dev-harness-board install-hooks` and `dev-harness-board uninstall-hooks` (any path to the command, including `bin/dev-harness-board` and `python3 .../dev-harness-board`), except with `--check`. This applies under every policy.
- **File rule:** ask before Edit/Write to, and shell writes into, the hooks folder `<git-common-dir>/dev-harness/hooks/**` (CH-17's untracked folder).
- **Must ask:** each form above, including after `&&`, `;`, `env`, `command`, and in `bash -c` text.
- **Must pass:** `dev-harness-board`, `--check`, `--json`, `install-hooks --check`, and reading the hooks folder.

Don't: weaken any existing rule; block (asking is enough).

## Done criteria

- Corpus rows for every Must ask and Must pass item.
- A mutation check: remove the new rule, and its rows fail.
- README guard list updated.
- The full suite passes. Review rounds: at most 2.
