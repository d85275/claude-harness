# CH-10: Text written into a file by a data heredoc is not a command

## Status

in progress (2026-11-23); owner: test files may be written with the file tools (shell commands still stop on a guard)

## Depends on

CH-03 (data-heredoc structural rule), CH-06, CH-07 (credential pass and size cap)

## Scope

The credential rule and the device-reset rule match their patterns anywhere in the command text, including the body of a heredoc that only writes a file. That blocked real work three times: CH-06 (`killall Simulator` as test text in `cat > file <<'EOF'`) and CH-07 twice (`.env.local` and an `AuthKey_*.p8` path as test text).

CH-03 already proves when a heredoc is pure data, for the push and protected-config regexes. The allowlisted owners are `git commit -F -`, `git tag -F -`, `cat > file`, `cat >> file` and `tee file`. The line must have no pipe, `$(`, backtick or `&`. The delimiter must be quoted, or the body must contain no `$`. The target must not be named again later in the command.

Apply the same rule to the credential pass and the device-reset rules: a hit that lies entirely inside a proven data-heredoc body is not a hit. Reuse CH-03's span detection; don't write a second one.

### Must pass (no block, no ask from these rules)

- `cat > tests/t.py <<'EOF'` with a body containing `"/x/.env.local"`, `/tmp/AuthKey_AB.p8`, `killall Simulator` or `xcrun simctl erase all`
- the same with `cat >>` and `tee file`
- `git commit -F - <<'EOF'` with a message mentioning `.env`

### Must still catch

- `cat ~/.ssh/id_rsa`, `cat .env` (not a heredoc)
- `cat > out <<'EOF'` followed by `; cat .env` (hit outside the body)
- `cat <<'EOF' | sh` and `bash <<'EOF'` with `killall Simulator` in the body (not a data owner)
- `python3 - <<'EOF'` / `node - <<'EOF'` with a credential path in the body (an interpreter runs it: still blocked)
- an unquoted delimiter with `$(cat .env)` in the body
- `cat > run.sh <<'EOF' ... EOF` followed by `sh run.sh` (target named again)
- every existing corpus row keeps its expectation

### Known gaps (document in README)

- Interpreter heredocs (`python3 -`) that only mention a credential path stay blocked. Write such test text with the file tools.

## Done criteria

- A mutation check shows the new rows fail when the span exemption is removed, and that the Must still catch rows fail when the exemption is applied to every heredoc.
- README known gaps updated. Full suite passes. Review rounds: at most 2.
